# 记忆

Avibe 记忆会把符合条件的 Workbench 和私聊消息提炼为按用户隔离的画像、事件与事实。
在**设置 > 记忆**中可以查看状态、当前画像、搜索结果、设置和处理日志。

## 处理日志

「日志」标签页会展示一条消息从捕获、创建 memcell、运行处理策略，到触发画像与当前
索引状态的过程。即使提供方负载日志处于关闭状态，普通处理时间线仍然可用。某个来源
数据库缺失、忙碌、格式异常，或关联标记已经过期时，对应部分会显示为不可用，其他部分
仍会继续显示。

Avibe 只有在能够证明调用属于当前登录用户时，才会把提供方调用关联到时间线。已认证的
Avibe Cloud 会话可以读取该用户自己的时间线和已保留调用，但不能读取其他用户的记录。

## 提供方负载日志

提供方负载日志是默认关闭、作用于整个安装的可选诊断设置。只有直接连接 Avibe 本机的
管理员才能启用或停用。启用后会影响使用该安装的所有用户，因此请先阅读设置页中的说明。

启用后，Avibe 会保留记忆处理过程中 LLM、多模态 LLM 和 Embedding 调用里经过脱敏且有
大小限制的请求与响应字段。它不会存储 Embedding 向量、附件字节、sidecar 原始
stdout/stderr，也不会记录无关的 Search 和 Get 调用。密钥、已配置的提供方 URL 和本机
绝对路径会被脱敏；过大的字段会截断或替换为省略标记。诊断负载仍可能包含敏感对话文本，
应按敏感数据控制访问。

关闭负载日志只会停止写入新记录，不会删除已经保留的记录。这些记录在正常过期或执行
「清除全部」前仍可读取。即使记忆或诊断捕获已关闭，留存清理仍会继续：记录最多保留
14 天，并且只保留最新的 5,000 次调用。

## 恢复与清除

记忆启用时，**重启引擎**只会替换托管 sidecar，不会修改记忆设置或删除已有数据。
记录器出现暂时性故障时可使用该操作。如果调用日志数据库损坏，重启后仍会保持降级状态。
此时必须执行**清除全部**，移除损坏的自有文件后才能恢复记录。

「清除全部」会移除此安装所拥有的专用本地记忆数据、处理队列、索引和已保留的提供方
调用诊断。它不会删除原始 Avibe 聊天、已经发送到提供方的副本、用户自行创建的快照、
普通日志、崩溃报告、备份或专用记忆目录之外的数据，也不是对存储设备的安全擦除。
