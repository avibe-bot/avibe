

## Code signing policy / 代码签名政策

Avibe submitted a SignPath Foundation application on November 2, 2026. It has
not been approved, and Windows releases are not signed through SignPath.
Current Windows installers are not Authenticode-signed; desktop update
signatures and macOS Developer ID signing are separate. Code signing does not
guarantee that SmartScreen reputation warnings disappear.
