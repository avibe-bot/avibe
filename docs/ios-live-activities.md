# Follow a Turn on the iPhone Lock Screen

While an Agent is working in a conversation, choose **Show on Lock Screen** above the message composer. The iOS app follows that one Turn. Starting a different activity ends the previous one.

The card shows the Agent name, the conversation title, the state and elapsed time. Names and titles are captured on the phone when tracking starts; renaming the conversation does not change an existing card. Message text, tool names and files are not included. The relay and Apple receive only the state and timestamps.

When the Turn needs an answer or approval, the card changes to **Needs you** and can light the screen. Tap it to return to the conversation and respond there. Completed, failed and stopped Turns remain on the Lock Screen for one hour. A running activity ends after eight hours. If the instance has not confirmed its state for forty minutes, the card indicates that it may be out of date.

Choose **Stop** in the conversation to stop showing the activity. Dismissing its card also stops tracking. Signing out or switching accounts or instances ends the activity immediately.

If Live Activities are disabled, the conversation offers **Settings**. Native notifications must also be enabled so the phone has a push registration. The entry appears only in an iOS app version that supports this feature and while a Turn is running.
